# diegoarangureen.github.io

Página provisional para el futuro blog personal y portfolio de proyectos.

- Web: https://diegoarangureen.github.io/
- Repositorio: https://github.com/diegoarangureen/diegoarangureen.github.io
- Publicación: GitHub Pages, rama `main`, carpeta raíz `/`.

Para verla localmente, abre `index.html` en el navegador. Los cambios publicados en `main` se despliegan automáticamente mediante GitHub Pages.

La dirección `github.io` no necesita comprar un dominio ni modificar DNS. Si más adelante se conecta un dominio propio, se configura en **Settings → Pages → Custom domain**.

Documentación: [GitHub Pages](https://docs.github.com/en/pages/quickstart).
