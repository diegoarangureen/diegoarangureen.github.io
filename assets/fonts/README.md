# Fonts

Literata (400–600) and Source Sans 3 (200–900), Latin WOFF2 subsets with Spanish accents. Served locally, with no external font requests at runtime. Combined size: approximately 68 KB.

Sources: [Literata](https://github.com/google/fonts/tree/main/ofl/literata), [Source Sans 3](https://github.com/google/fonts/tree/main/ofl/sourcesans3). WOFF2 obtained through their Google Fonts stylesheets. Each SIL Open Font License is included beside the font.
